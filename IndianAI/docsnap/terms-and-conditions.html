2. Description of the App

DocSnap is a free Android application that provides 21 document management tools including, but not limited to:

  • PDF creation tools (Image to PDF, Document Scanner, QR Code to PDF)
  • PDF editing tools (Merge, Split, Rotate, Crop, Reorder Pages, Remove Pages)
  • PDF conversion tools (PDF to Images, PDF to Text via OCR, PDF to Word)
  • PDF optimization tools (Compress PDF, Blank Page Remover)
  • PDF security tools (Encrypt, Decrypt, Add/Remove Watermark)
  • PDF utility tools (Add Page Numbers, Metadata Editor, Thumbnail Preview)

The App is designed to process documents locally on your Android device. The web version of DocSnap (this website) provides information about the App and a UI preview only — no actual document processing is performed on the website.
