Important: Google Gemini API Key Required

InshortAI uses the Google Gemini API to power its AI responses. To use the real app, you must provide a valid Google Gemini API key within the application settings. The API key connects your app to Google's AI service. You can obtain a free API key from Google AI Studio (makersuite.google.com). Your API key is stored locally on your device and is never sent to our servers.
